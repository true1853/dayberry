# Phase 1 — Validation Strategy

> Контракт проверок для безопасного изменения эскроу и миграции живых данных.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Node.js 22 built-in `node:test` |
| **Config file** | Не требуется; Wave 0 добавляет изолированные SQLite-фикстуры |
| **Quick run command** | `node --test test/escrow.integration.test.mjs` |
| **Full suite command** | `node --test --test-concurrency=1 test/*.test.mjs` |
| **Estimated runtime** | До 120 секунд для локального полного набора; восстановленная копия проверяется отдельно |

## Sampling Rate

- **После каждого коммита задачи:** целевой `node --test` для изменённого контура
- **После каждой волны:** `node --test --test-concurrency=1 test/*.test.mjs`
- **После изменений Prisma:** генерация клиента, применение миграций к одноразовой базе и `npm run build`
- **Перед проверкой этапа:** полный набор тестов и репетиция на восстановленной копии должны пройти
- **Максимальная задержка быстрой обратной связи:** 120 секунд

## Evidence Artifacts

- Checksum и размер исходного snapshot; commit приложения, lockfile и миграции.
- Checksum SQL-миграции; версия и compile options SQLite; WAL/journal/synchronous settings.
- Результаты `integrity_check`, `foreign_key_check`, counts, audit JSON и полный список неоднозначных ID.
- Backfill manifest и hash; доказательство, что второй запуск ничего не изменил.
- Изменения балансов, резервов, выплат и счётчиков; TAP-вывод тестов; boot/smoke log.
- Состояние feature flags, оператор и timestamp; длительность и результат восстановления.

## Security Exit Gates

- [ ] Ни один положительный резерв новой сделки не фиксируется без точной FK-связи, `refType/refId` и уникального business key.
- [ ] Повтор или гонка завершения, отмены либо спора не создаёт второго изменения баланса, счётчика или выплаты.
- [ ] Исключение после любой внутренней записи откатывает всю авторитетную транзакцию.
- [ ] Ни один путь не ищет резерв по пользователю, времени создания или принципу «последний замороженный».
- [ ] Неоднозначные строки не изменяются автоматически и перечислены оператору.
- [ ] Скрипт репетиции не может применить изменения к живому пути без явного `--apply` и подтверждённого snapshot.
- [ ] Резервная копия проходит восстановление, целостность и доменный аудит до мутации продакшена.
- [ ] Rollback не возвращает старую небезопасную логику выбора резерва.
